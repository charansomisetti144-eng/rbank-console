## 📖 Project Overview

RBank is a feature-rich banking management system that simulates real-world banking operations through Customer, Employee, and Manager modules. The system allows account management, transactions, customer management, and various financial calculations.

---

## 🚀 Features

### 👤 Customer Module
- Customer Login
- View Profile
- Balance Inquiry
- Deposit Money
- Withdraw Money
- Transfer Money
- Change PIN
- Transaction History

### 👨‍💼 Employee Module
- Employee Login
- Create Customer Account
- Search Customer
- Update Customer Information
- Delete Customer Account
- View All Customers

### 👨‍💻 Manager Module
- Manager Login
- View Total Customers
- View Total Bank Balance
- View Highest Balance Customer
- View Lowest Balance Customer
- Search Customer
- Bank Statistics

### 🧮 Financial Calculators
- Interest Calculator
- Fixed Deposit Calculator
- Recurring Deposit Calculator
- EMI Calculator
- Loan Eligibility Calculator
- Currency Converter
- Age Calculator
